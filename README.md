# Debt-Manager

This is my very first project: a simple console application for managing debts, built with C# and .NET.

## Features

- Add debts
- Record payments
- Display current debts
- Validate user input

## Technologies Used

- C#
- .NET

## Getting Started

1. Clone this repository.
2. Open `Program.csproj` in Visual Studio.
3. Run the application.
